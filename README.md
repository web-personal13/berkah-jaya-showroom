# Berkah Jaya Auto Group - Showroom Mobil Metro Lampung

Website resmi **Berkah Jaya Auto Group**, dealer dan showroom mobil terpercaya di Kota Metro, Provinsi Lampung.

Desain website ini mengadopsi standar modern dealership automotive (Summit Auto Group aesthetic), responsif di semua perangkat (Desktop, Tablet, dan Mobile/Smartphone).

## 🚀 Fitur Unggulan
* **Responsive Modern UI**: Desain bersih dengan palet warna hitam obsidian, putih bersih, dan aksen *Dealer Crimson Red*.
* **Pencarian Cepat (*Search Inventory*)**: Filter berdasarkan Merek, Model, Tipe Bodi, dan Rentang Harga.
* **Katalog Unit Lengkap (*Popular Picks*)**: Kartu mobil modern dengan badge tahun, spesifikasi lengkap, harga tunai, estimasi DP, dan modal detail interaktif.
* **Simulasi Kredit Interaktif**: Menghitung estimasi cicilan per bulan dan DP dengan opsi tenor 1-4 tahun, langsung terhubung ke WhatsApp.
* **Dual Promo Banners**: Fasilitas pengajuan kredit kilat (*Drive Now, Pay Your Way*) dan konsultasi tukar tambah (*Value Your Trade*).
* **Fasilitas & Lokasi Showroom**: Foto fisik showroom di Jl. Soekarno Hatta No.43 16b Kota Metro dengan petunjuk arah Google Maps.
* **Tombol Kontak Melayang (*Unified Floating Action*)**: Akses cepat ke WhatsApp Official dan Instagram @yukocalatrava.

## 🛠️ Teknologi
* HTML5 Semantik
* Tailwind CSS
* Font Awesome 6
* Google Fonts: Poppins
* JavaScript Vanilla murni (No external framework dependencies)
